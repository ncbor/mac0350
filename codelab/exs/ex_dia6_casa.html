Exercícios de Casa: Introdução ao SQL

Continuando a trabalhar nas funcionalidades do seu projeto, para esta parte, faremos algo similar ao que foi feito nos exercícios de sala, mas dando enfase nas necessidades do seu projeto.

Os exercícios foram pensados para servir como guia durante a criação do seu banco de dados.

Apenas o produto do item 3. Criação do Schema deverá estar presente em seu repositório para avaliação.

1. Definição dos Dados Trabalhados

Defina: Quais serão as informações que sua aplicação irá manipular?

Você consegue dizer se existe algum tipo de dado que poderia ser agrupado?

2. Modelagem do Banco de Dados

Defina: Caso haja algum tipo de dado agrupado, existe algum tipo de relação entre estes grupos?

Caso haja relação, você consegue dizer quem está relacionado a quem?
Isto é: dizer quem é chave primária e quem é chave estrangeira?

3. Criação do Schema

Tarefa: Crie o script SQL para criar todas as tabelas necessárias para seu banco de dados, incluindo as chaves primárias e estrangeiras apropriadas.

A partir deste script, utilize uma ferramenta de criação de diagramas, para gerar uma representação de seu modelo.
Sugestão: cole seu script em https://www.drawdb.app/, e salve em seu repositório, o diagrama gerado.
Você é livre para modificar e personalizar o diagrama como quiser, não há formato definido.
Este diagrama poderá ser especialmente útil em seu Pitch.

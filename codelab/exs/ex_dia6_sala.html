Seu trabalho é completá-lo para que sejam adicionadas, as seguintes informações:

  • Entregador
    1. ID do entregador - entregador_id - (INTEGER)
    2. Nome do entregador responsável - nome - (TEXT)
    3. Contato do entregador responsável - contato - (TEXT)
  • Cliente
    1. ID do cliente - cliente_id - (INTEGER)
    2. Nome do cliente - nome - (TEXT)
